# Scope Classification

## v1.00

### Required Now
- one factory plot
- one production route
- deterministic item movement
- seller
- roughly 12 distinct launch machines
- machine placement/move/remove
- Coins
- server-authoritative rolling
- compact inventory
- a few capacity upgrades
- saving/loading
- basic analytics
- mobile building support
- basic feedback/audio
- active-item cap
- basic anti-exploit validation

### Valuable Later
- choice-of-three roll if it does not delay launch
- filters/sorting
- pity tuning
- modular conveyor placement
- additional machine categories
- detailed production stats
- cosmetics

### Scope Creep
- pets
- rebirth tree
- multiple worlds
- trading
- clans
- player marketplace
- dozens of currencies
- PvP
- elaborate quests
- advanced research
- hundreds of machines
- global events

## v2.00

### Required Now
- modular logistics foundation
- multiple lines
- splitters/mergers
- richer reusable machine behavior
- better building tools
- layout serialization upgrade
- performance instrumentation
- production statistics

### Valuable Later
- blueprints
- advanced sorters
- specialized factory zones
- layout sharing
- automation presets

### Scope Creep
- trading
- economy marketplace
- clans
- giant social hub
- prestige before progression design is validated
- live event framework

## v3.00

### Required Now
- progression data model
- collection
- research or equivalent specialization
- challenge framework
- secure factory showcase/visit model
- records/leaderboards if fair
- retention-oriented goals tied to factory play

### Valuable Later
- co-op tasks
- limited shared objectives
- cosmetic social rewards
- prestige if validated

### Scope Creep
- unrestricted trading
- auction house
- mandatory co-op progression
- clan wars
- social systems that bypass factory gameplay

## v4.00

### Required Now
- data-driven machine content
- content validation
- feature flags
- live configuration boundaries
- migration tooling
- debugging/admin tools
- observability
- rollback-safe operational practices
- seasonal content pilot

### Valuable Later
- richer internal dashboards
- content authoring UI
- economy simulation at larger scale
- blueprint moderation tools

### Scope Creep
- building an enterprise backend stack
- custom infrastructure with no proven operational need
- fully dynamic code delivery
- massive content cadence that a solo developer cannot sustain
