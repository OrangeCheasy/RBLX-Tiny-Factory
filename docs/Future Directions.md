# Future Directions — Conditional Only

No v5.00 scope should be committed until v4.00 operations and product data justify it.

Possible validated paths:

## Factory Worlds
Different environments that meaningfully change machine constraints, resources, or routing.

## Cooperative Mega-Factories
Shared production projects where each player contributes a section without making solo play obsolete.

## Blueprint Sharing
Players publish layouts or partial factory patterns. Requires version compatibility, moderation, and anti-exploit handling.

## Advanced Prestige
Only if resets create new strategy spaces, machine pools, or specialization—not merely a larger multiplier.

## Automation Scripting
Potentially powerful but high complexity and exploit risk. Should be heavily constrained if ever explored.

## Market / Trading Systems
Highest economy/security risk. Requires strong duplication prevention, item identity rules, sink/source design, and evidence that trading improves rather than replaces factory gameplay.

## Server-Wide / Global Production Events
Could create community goals while keeping individual factory contribution meaningful.

The decision rule remains:

> Build the next scalability layer only when the current game proves that players want more of the factory itself.
